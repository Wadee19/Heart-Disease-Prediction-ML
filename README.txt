# Heart Disease Prediction Using Machine Learning 🫀

This project applies multiple machine learning models to predict the presence of heart disease based on patient clinical data. The goal is to compare and evaluate different models in terms of accuracy, recall, and precision.

## 📁 Dataset

- Source: [Kaggle Heart Disease Dataset](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction)
- Format: CSV
- License: Public Domain or CC0 (TBD - please confirm source & citation)

## 🧠 Models Used

- Logistic Regression
- Random Forest
- Support Vector Machine
- Decision Tree
- K-Nearest Neighbors
- Naive Bayes

## 🔬 Evaluation Metrics

- Accuracy Score
- Confusion Matrix
- Classification Report
- ROC-AUC Curve

## 🧰 Tools & Libraries

- Python
- scikit-learn
- pandas
- matplotlib
- seaborn

## 📊 Visualizations

The notebook includes correlation heatmaps, distribution plots, and model performance comparison charts.

## 📌 How to Run

1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Run the notebook
